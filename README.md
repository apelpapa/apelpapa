## Selected projects

### Homestead Puppies — Full-stack business application

Built a public catalog and authenticated administration system for a family business. The backend manages catalog records, availability, and image uploads, with PostgreSQL-backed sessions and S3/CloudFront media storage and delivery.

Added a React and TypeScript frontend through a versioned Express API while preserving the original EJS site and administration workflow. The project demonstrates extending an existing application, shared data access, and automated deployment.

**Stack:** React, TypeScript, Node.js, Express, PostgreSQL, AWS S3, GitHub Actions

[Backend and admin source](https://github.com/apelpapa/HomesteadPuppies) · [React frontend source](https://github.com/apelpapa/homestead-puppies-modern) · [Live site](https://homesteadpuppies.org/)

### Jot Notes — Full-stack notes application

Built a React and TypeScript application with browser-local notes, private account notes, and a separate public feed. The Express API verifies authentication tokens and scopes private-note queries to the signed-in user. The interface handles persistent browser storage, account state, and loading and error states.

**Stack:** React, TypeScript, Node.js, Express, PostgreSQL, Supabase Auth

[Source](https://github.com/apelpapa/jot-notes) · [Live app](https://jot-notes.app/)
